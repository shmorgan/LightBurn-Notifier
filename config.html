Pairing secret

Status: checking…

On the LightBurn computer run pair.ps1 (add -IncludeProject to also show the project filename), click Allow in LightBurn within 30 seconds, then paste the secret it prints here. It is checked against LightBurn before saving, and never shown again.

Camera view

Off by default. LightBurn provides the most recent camera capture (the same image as File > Save Background Capture), not live video, so the picture updates when LightBurn captures a new one. While this is on, anyone who can open the status page can see your workspace. It needs a pairing with project access (pair.ps1 -IncludeProject) and a camera set up in LightBurn.
